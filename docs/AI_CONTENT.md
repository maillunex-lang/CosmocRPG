# Учёт ИИ-контента

Реестр материалов, созданных с помощью ИИ. Нужен для раскрытия информации при публикации (RuStore и другие площадки), для проверки лицензий и для оценки рисков. Заполняется при добавлении каждого ИИ-ассета.

## Что нужно учесть перед публикацией

- Права. По условиям использования сервиса права на результат принадлежат пользователю, но охраноспособность изображений, созданных ИИ, в разных странах трактуется по-разному. Эксклюзивные права на сами изображения могут быть ограничены. Это юридический вопрос владельца; я не проверял актуальные условия.
- Раскрытие. Правила RuStore и других площадок, а также законы о маркировке ИИ-контента (в том числе в ЕС) могут требовать пометки. Актуальные требования я не проверял: проверить до первой публикации (ориентир: навык `ai-disclosure`).
- Код проекта пишется с помощью ИИ-ассистента (Claude Code). Это отражено в истории коммитов (строка `Co-Authored-By`).

## Правило

Каждый новый ИИ-ассет (изображения, звук, музыка, тексты, модели) добавляется в эту таблицу с датой, инструментом, автором запроса и исходными файлами.
