# Сервер

Опора: `docs/ARCHITECTURE.md` («Сервер (MVP)»). Python, SQLite, переход на PostgreSQL по необходимости. Один процесс, без микросервисов и очередей.

Клиенту не верить. Он шлёт id стадии и состав из 5 id.
Сервер сам берёт статы, прогоняет тот же бой по seed (скилл `auto-battle`) и только потом выдаёт награду.
Идемпотентность: `battle_id` уникален, повтор запроса не даёт награду дважды.

AFK-награда считается от времени последнего сбора, измеренного на сервере, с потолком часов.
Призыв крутит сервер, шансы и pity в базе, ответ — кого выдали. Клиент не присылает редкость или золото.
Нет ручки «добавь золото».

Аккаунт: гость, затем привязка. Пароль только хешем. Сессия — случайный токен со сроком.
Ручки узкие: регистрация гостя, профиль, состав, запуск боя, события, награды, AFK-сбор.
Лимиты частоты на призыв и сбор.

Секреты только в окружении или `.env` вне git. Порты наружу не открывать без отдельного разрешения: разработка по localhost или SSH-туннелю.

Выход: схема таблиц, список ручек и что проверяет каждая.
