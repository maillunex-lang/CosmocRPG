# AIC-030 — долгосрочные цели с цепочкой действий

## Принцип

AI не летает без цели. Каждое движение или атака — шаг в текущей долгосрочной цели.

## Сделано

- `server/internal/aiciv/goals.go` — `GoalRunner`:
  - Цель `farm_credits`: **find_target → approach → attack → (retreat при низком корпусе) → wait → find_target**.
  - Если цели нет — агент стоит на месте (не бродит).
  - При низком здоровье прерывает цепочку и отступает.
- `FarmController.RunGoalOnce` — входит в мир и запускает `GoalRunner`.
- В `main.go` под флагом gateway запускается один агент с целью `farm_credits`.

## Что ещё нет

- Другие цели (добыча→продажа, квесты, торговля).
- Utility-выбор между несколькими целями.
- Память влияет на выбор цели, не только на отступление.
- Несколько агентов с разными целями.

Флаги выключены по умолчанию.
