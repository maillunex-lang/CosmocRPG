# RPG-0: схемы данных и расчёт (пакет `server/internal/rpg`)

Статус: код и тесты готовы, **к игре не подключено** (production и клиент не затронуты). Подключение — RPG-1…RPG-6. Числа — ориентиры для разработки, не утверждённый баланс.

## Характеристики
- **Корабль, 19** (`StatID`): защита — `hull`, `shield`, `armor`, `resist`; атака — `damage`, `accuracy`, `range`, `crit_chance`, `crit_damage`; системы — `speed`, `maneuver`, `energy`, `energy_regen`, `sensors`; экономика — `cargo`, `mining`, `fuel_use`, `repair_cost`, `haul`.
- **Пилот, 6** (`Attribute`): `piloting`, `tactics`, `engineering`, `energetics`, `analytics`, `logistics`. Таблица «очко → характеристика корабля» — данные (`Config.AttributeEffects`).

## Расчёт `Compute(cfg, input) → Result`
Чистая функция: итог считается с нуля из снимка, вход не меняется. Слои по порядку: **уровень корабля → характеристики пилота → таланты → мастерство → модули → временные эффекты**. Внутри слоя: все `add`, затем одно умножение на `(1 + Σ mul)`. После слоёв — потолки `Caps`. Каждый источник (`source`) учитывается один раз (повтор отбрасывается с предупреждением); результат не зависит от порядка элементов во входе. Результат содержит `Final`, `Breakdown` (разбивка по источникам для подсказок клиента) и `Warnings` (неизвестные таланты, некорректные вклады).

## Кривые опыта
`Curve{MaxLevel, Base, Growth}`: переход n → n+1 стоит `round(Base × Growth^(n−1))`. Стартово: пилот 1–100 (100, ×1,08), корабль 1–50 (150, ×1,12). Очки: характеристики — 2 за уровень выше первого, таланты — 1 за уровень выше первого.

## Дерево талантов (`TalentTree`, версионируется)
Узел: `id`, `name`, `branch`, `tier`, `cost` (очков за ранг), `max_rank`, `requires[]`, `effects[] {stat, op, per_rank}`. Проверка `Validate()`: уникальные id, известные ветви, стоимость/ранг/ярус ≥ 1, эффекты с известными характеристикой и операцией, требования существуют, ярус выше требований, нет циклов. Первые ветви (решение владельца): бой, добыча/промышленность, торговля/логистика, исследование; 40–60 узлов — этап RPG-3.

## Тесты (`go test ./internal/rpg`)
Идемпотентность и чистота, независимость от порядка, порядок слоёв и «add до mul», однократность источников, сброс таланта убирает ровно свой вклад, уровень корабля и характеристики, потолки и неизвестные входы, кривые (монотонность, обратимость `LevelFor`), проверка дерева (10 видов ошибок и цикл).
