## Инвентаризация

В checkout обнаружены три Markdown-файла QUESTJOB: [FinalQuest](../../QUESTJOB/FinalQuest.md), [PilotProgression](../../QUESTJOB/PilotProgression.md), [loot](../../QUESTJOB/loot.md). Автоматический подсчёт заголовков второго уровня с ID обнаружил 45 различных ID в FinalQuest и 13 в PilotProgression; в loot решения оформлены заголовками первого уровня, поэтому этот подсчёт не применим. Это количество заголовков, а не подтверждённое количество утверждённых решений. Требуются полное чтение и проверка статуса каждого решения.

Основная карта: [ROADMAP](../ROADMAP.md), данные задач: [tasks.json](tasks.json), схема: [SCHEMA](SCHEMA.md), реестр: [REQUIREMENTS_INDEX](REQUIREMENTS_INDEX.md). Используется существующий журнал [ошибок оснащения](../ships-rpg/ERROR_LOG.md); его область необходимо учитывать при решении о журнале для других подсистем.

## Предварительные находки

- Схема карты использует статусы TODO, IN_PROGRESS, BLOCKED, DONE, FAILED, DEFERRED; запрошенные READY и NEEDS_DECISION отсутствуют. Перед расширением необходимо согласовать схему, валидатор и генератор; существующие статусы активной работы не менять.
- [Модуль квестов](modules/QUESTS.md) упоминает `GearScore.md` и `HiddenMap.md` без путей; их расположение и актуальность необходимо проверить.
- В tasks.json найдена ссылка на FinalQuest без конкретного раздела. Полнота покрытия решений и остальные ссылки ещё не проверены.
- Утверждённое описание не является свидетельством реализации; прежние статусы DONE требуют отдельной проверки доказательств, без автоматического изменения.

## Продолжение

1. Прочитать все три файла целиком, классифицировать решения по фактическому статусу и зафиксировать точные якоря.
2. Сопоставить каждый пункт с существующими задачами и кодом только для чтения; отдельно зафиксировать SPEC_GAP и противоречия, не выдумывая решения.
3. Обновить существующие карточки и добавить недостающие с зависимостями и критериями, сохранив активные назначения и стадии проекта.
4. Проверить ссылки, якоря, уникальность ID, покрытие и циклы; повторно выполнить `python3 tools/validate_roadmap.py` и проверить diff.

Проверка существующего валидатора на базе: успешно, 33 задачи, 100 внешних ID. Это не проверка полноты QUESTJOB, работающих якорей или фактической реализации.
