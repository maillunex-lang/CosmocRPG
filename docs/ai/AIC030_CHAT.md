# AIC-030 — общение без скриптовых повторов

## Принцип

AI не спамит одними и теми же фразами. Реплики привязаны к текущей цели и к последним сообщениям в канале.

## Сделано

- `server/internal/aiciv/chat.go` — `ChatSpeaker`:
  - Глобальный антиповтор (хеши последних 24 реплик).
  - Короткий контекст канала (последние 6 сообщений).
  - `LineForGoal` — разные фразы по цели (бой / добыча / разведка), ротация по времени.
  - `FollowUp` — короткий ответ на последнюю реплику в канале (не сам себе).
- `GoalRunner` периодически пишет реплику по своей цели и может ответить на предыдущую.
- В `main.go` создаётся `ChatSpeaker` и передаётся агенту.

## Ограничения

- Нет LLM. Фразы заранее заданы, но выбираются по контексту и не повторяются.
- Пока один агент. Многоголосые диалоги AI↔AI — следующий шаг.
- Существующий AI-2 (Studio engine) не заменён.

Флаги выключены по умолчанию.
