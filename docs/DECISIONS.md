# Журнал решений

## Утверждённые решения владельца (не менять без согласования)

| № | Решение |
|---|---|
| 1 | Гибридная галактика: межзвёздная карта и общие игровые локации внутри звёздных систем. |
| 2 | Гибридное управление: автопилот, ручное перемещение, автоатаки и управляемые способности. |
| 3 | RPG-классы кораблей и специализации. |
| 4 | Бои непосредственно в общем космосе, без обязательного перехода на отдельный экран. |
| 5 | Флагман и постепенно открываемые корабли сопровождения, максимум пять кораблей в эскадре. |
| 6 | Динамические фракции, репутация, дипломатия, конфликты. |
| 7 | Постоянные системы и процедурно расширяемый фронтир. |
| 8 | Живая региональная экономика, торговля игроков и AI, спрос и предложение. |
| 9 | Добыча, переработка, производство, исследования, кораблестроение. |
| 10 | Корпорации, космические базы, территории и войны. |
| 11 | Полностью открытое PvP практически во всём космосе. Безопасных PvP-зон нет; допускается ограниченная техническая защита стартового обучения. |
| 12 | Полноценная AI-цивилизация: автономные капитаны, экономика, память, отношения, корпорации, войны. |
| 13 | Живая idle-империя: офлайн-добыча, торговля, исследования, производство, фоновые задания. |
| 14 | Гибридная монетизация без эксклюзивной платной боевой мощи: косметика, пропуск, подписка, ограниченные ускорения. |
| 15 | Модульная онлайн-архитектура с постепенным расширением. |

## Технические решения

| Дата | Решение | Обоснование |
|---|---|---|
| 2026-11-08 | Стек: Godot 4.7 (клиент), Go (сервер), PostgreSQL, React + TypeScript (админка), Docker Compose, GitHub Actions. | Задан в мастер-промпте №1. |
| 2026-11-08 | Работаем в репозитории `maillunex-lang/CosmocRPG` (приватный), монорепозиторий. | Подтверждено владельцем. |
| 2026-11-08 | VPS = рабочая машина разработки (`78.17.214.25`, Ubuntu 24.04). Другие проекты и их ресурсы не используются. | Подтверждено владельцем. |
| 2026-11-08 | Домена пока нет: доступ к игровому серверу по IP, HTTP/WS без TLS. Админка слушает только localhost, доступ через SSH-туннель. | Нет домена; пароли админки нельзя пускать по открытому каналу. К релизу обязателен домен и TLS. |
| 2026-11-08 | Для Android-тестов нужен ws:// к IP VPS. **Проверено на устройстве 2026-11-08 (iQOO 15R, release-APK):** `ws://` к IP VPS работает без дополнительных настроек Android (WebSocketPeer использует собственные сокеты), задержка 83–101 мс. Исключение cleartext в манифесте не требуется. | Android блокирует HTTP для своих сетевых API, но не для сокетов Godot. |
| 2026-11-08 | Go 1.22 из пакетов Ubuntu. | Достаточно для Этапа 00; обновить при необходимости. |
| 2026-11-08 | Автодеплой в production не включается без согласования. | Требование промпта. |
| 2026-11-08 | **Размер и поставка клиента (требование владельца):** APK желательно не более 100 МБ; игровые ресурсы (модели, текстуры, звук, контент) скачиваются внутри игры; обновления самого APK тоже можно скачивать через игру. | Лёгкая установка, быстрые обновления контента без новой сборки. |
| 2026-11-08 | Ресурсы доставляются как версионируемые наборы (resource packs / PCK) с подписанным манифестом и проверкой хешей. В наборах только данные (модели, текстуры, звук, сцены без исполняемого кода); логика остаётся в APK. | Безопасность: скачанный код был бы удалённым исполнением кода. |
| 2026-11-08 | **Канал распространения (решение владельца):** APK напрямую (свой сайт/ссылка), позднее RuStore. Google Play не используется. Поэтому обновление APK скачивается и устанавливается самой игрой. Требования: Android-разрешение на установку пакетов (REQUEST_INSTALL_PACKAGES, пользователь подтверждает один раз), загрузка только по HTTPS, проверка SHA-256 и подписи, подпись APK постоянным ключом. Перед публикацией в RuStore сверить его правила на самообновление и при необходимости перейти на механизм обновления RuStore. | Прямое распространение разрешает самообновление; RuStore имеет собственные правила. |
| 2026-11-08 | **Требование владельца к админке:** через Universal Space Studio можно настраивать весь игровой функционал, **включая замену ресурсов** (3D-модели кораблей, графика, звук и т. д.) без выпуска нового APK. | Контент живёт на сервере и доставляется в игру (см. ARCHITECTURE: поставка контента и менеджер ресурсов). |
| 2026-11-08 | Резервные копии БД: ежедневно 03:30 (cron пользователя), `infrastructure/backup.sh`, хранение 14 дней в `~/backups/cosmoc`; проверка восстановления `infrastructure/restore-test.sh` разворачивает копию во временную базу и сверяет строки. | Требование промпта: бэкап и тест восстановления. Копии пока на том же VPS: нужна копия вне сервера. |
| 2026-11-08 | Файрвол `ufw` включён: входящие только SSH (22) и игровой порт (8080). Docker публикует порты в обход `ufw`, поэтому админка привязана к `127.0.0.1`, а PostgreSQL и админ-API не публикуются. | Защита не должна зависеть от `ufw`. |
| 2026-11-08 | Тесты БД используют изолированные временные схемы (`internal/testdb`). | Параллельные пакеты мешали друг другу в общей схеме. |
