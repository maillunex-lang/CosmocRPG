# Реестр действий и серверные контракты

Статус: проект контрактов. **На сервере сейчас реализованы только `ping`/`pong` и служебные `hello`/`error`** (см. docs/API.md). Все остальные серверные команды ниже предложены и ещё не существуют; до их появления кнопки работают через `DemoGateway` (плашка «Демо») или показывают «Скоро».

## Общие правила контракта

- Команда: `{ "type": "<домен>.<глагол>", "id": "<uuid клиента>", "payload": {…} }`. `id` — ключ идемпотентности: повтор с тем же `id` не выполняется дважды, сервер возвращает прежний результат.
- Ответ: `{ "type": "ack", "id": "<тот же id>", "payload": {…} }` или `{ "type": "error", "id": …, "payload": { "code", "message" } }`. События мира приходят без `id`.
- Состояние ожидания: кнопка блокируется до ответа или тайм-аута (по умолчанию 10 с), показывается индикатор. Повторное нажатие игнорируется.
- Тайм-аут и потеря связи: ошибка с кнопкой «Повторить» (с тем же `id` для идемпотентных команд).
- Клиент не считает валюту, ресурсы, урон, награды, права; показывает то, что вернул сервер.
- Подтверждение: модальное окно; для покупок показывает цену, полученную от сервера; если цена изменилась, показывается новое подтверждение.

Колонки: **ID** действия · **Экран** · **Доступно когда** · **Серверная команда / событие** · **Подтв.** (подтверждение игрока) · **Идемп.** (нужен ключ идемпотентности) · **Сервер**: ✔ есть, ✖ нет (mock/«Скоро»), клиент — только клиент.

## Контракт состояния мира (шлюз данных `UiGateway`, UI-02)

Экраны получают данные только через шлюз (`client/ui/gateway/ui_gateway.gd`) и ничего не считают сами. Сигналы: `state_updated(state)`, `alert_raised(id, text)`, `alert_cleared(id)`, `notification(text)`, `command_failed(action, reason)`. Реализация сейчас одна: `DemoGateway` (данные не с сервера, `is_demo() == true`, интерфейс показывает плашку «Демо»). Серверный шлюз появится вместе с серверным миром (Этап 01); подставляется вместо демо без изменений экранов.

Поля `state`: `mode` («demo» / «server»); `player` {name, level}; `system` {id, name, background} (профиль фона системы); `ship` {name, hull, hull_max, shield, shield_max, energy, energy_max, pos, dir}; `credits`; `objects[]` {id, name, kind: player|ai|hostile|station, stance: hostile|neutral|friendly, is_ai, pos, dir, hull, hull_max}; `target_id`; `target_in_range`; `attacking`; `auto_skills`; `autopilot`; `skills[]` {slot, name, energy_cost, cooldown, cooldown_left, needs_target}; `combat` {in_combat}; `quests[]` {title, progress, goal}; `chat[]` {channel, author, text}. Все значения (урон, дальность, энергия, перезарядка, награды) определяет источник данных; клиент их только показывает.
