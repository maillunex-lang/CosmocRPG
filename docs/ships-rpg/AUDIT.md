- `rpg/{stats,compute,talents,progression}.go`: 19 типизированных статов, 6 атрибутов; чистый слоистый расчёт, caps, защита от повторных источников, проверка дерева. Переиспользовать, не создавать второй движок модификаторов.
- `pilot`, `shipxp`, миграции 0014/0015: pilot XP и xp_grants, экземпляр уникален по player_id+ship_type, идемпотентные начисления. Лимиты 60/30. Нет независимых копий одного типа, оборудования, билдов, рангов и специализационного XP. Миграции 0001…0018 добавочные; в этой сессии БД не меняется.

Новые силуэты делать процедурными, без финальных GLB.

## Риски и конфликты
1. АР-4 требует 60/30 и сохранённое мастерство, новый запрос — 100/50 + специализация 20. АР-2 задаёт 10–15 узлов, новый — 6 + усиление. На момент аудита запрошено уточнение. Впоследствии владелец подтвердил новые требования: блокировка снята, caps 100/50 реализованы SR-014a; деревья ещё TODO. Мастерство и дерево пилота не удалять.
2. 15 моделей / 12 классов (формулировку «15 корпусов» в критериях читать как модели; у корветов и фрегатов общий класс). Решение SR-ADR-001.
3. Сервер может загрузить старую активную версию из PostgreSQL вместо нового embedded seed. Нужен явный совместимый upgrade, не перезапись админских значений.
4. Неизвестные формулы/баланс не утверждены. Не копировать один эффект под 72 именами. Все новые числа предварительные, до runtime нужны отдельные контракты и тесты.
5. Здесь отдельное cloud-окружение, не VPS. Ни production, ни чужие проекты, ни секреты не исследовались. Реальное состояние production не проверено.

## Внедрение и затрагиваемые области
Сначала типизированный реестр идентичностей + schema и проверки существующих ID без изменения runtime. Затем паспорта/бюджеты, эффекты и умения малыми семействами, модули и достижимость всех открытий. Только после этого server dispatch, оборудование/транзакции, прогрессия/добавочные миграции, Godot UI и визуалы, общие NPC/PvP правила, нагрузка. Затронутся world, rpg, shipcatalog, pilot/shipxp, db, ws/admin, client/ui/ships, HUD, gateway, tests и CI; не трогать несвязанные квесты/ИИ/сайт.
