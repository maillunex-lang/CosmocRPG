# Иконки интерфейса

Набор **Lucide** (https://lucide.dev, исходники https://github.com/lucide-icons/lucide), лицензия ISC (текст: `LICENSE-lucide.txt`).
Скачаны 2026-11-08 без изменений, кроме замены `currentColor` на `#ffffff`: иконки белые и перекрашиваются через `modulate`.
Подключение: `ui/icons.gd` (`Icons.tex("coins")`). Новые иконки добавлять сюда же и записывать в этот файл.
Использованы: badge-check, check, coins, crown, flame, fuel, gem, globe, lock, package, palette, pickaxe, rocket, settings, shield, shopping-cart, skull, sparkles, star, store, user, x, zap.
