## Главные правила

- Только горизонтальная ориентация (Landscape). База 16:9 (1280×720), адаптация под другие горизонтальные соотношения.
- Клиент не источник истины: валюта, ресурсы, бой, награды, права доступа считает сервер.
- Нет API: изолированный mock-адаптер с явной пометкой «Демо», в рабочем режиме выдуманные данные не показываются.
- Нет возможности: состояние «Скоро» с пояснением, никаких декоративных кнопок.
- Один этап — один проверяемый коммит.
