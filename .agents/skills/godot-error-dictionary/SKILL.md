# godot-error-dictionary: Уралия

## Порядок работы
1. Сверь реальную версию Godot и `client/project.godot`. Текущий проект: портретный 2D 720×1280, `AnimatedSprite2D`, не 3D MMORPG.
2. Перед решением изучи `docs/ENVIRONMENT.md`, `docs/PROGRESS.md`, `docs/CI.md`, `docs/pipeline/` и точный лог ошибки.
3. Известные ограничения VPS: отсутствие DISPLAY, необходимость `xvfb-run` для визуальных проверок, headless импорт переводов, ограничения некоторых команд Godot MCP. Не меняй конфигурацию MCP.
4. Предложи минимальное исправление; проверь повторным импортом или тестом. Записывай в `docs/godot-error-dictionary.md` только проверенные случаи: сигнатура, версия, причина, исправление, команда, коммит.
5. Если причина не подтверждена, помечай UNVERIFIED; не запускай непроверенные внешние скрипты.

## Общие ограничения
Работать только в `maillunex-lang/ufa5` по согласованной задаче. Сверять утверждённые решения с кодом, не переносить 3D MMORPG-механики из AnimeAutoMMORPG. Не трогать Claude MCP, Codex MCP, VPS, другие репозитории, занятые порты, production, секреты и платежи. Никаких внешних зависимостей или исполняемых хуков без аудита и разрешения. Отчёт о файлах, реальных проверках, рисках и следующем шаге.

## Происхождение
Оригинальная адаптация рабочих принципов из собственного репозитория `maillunex-lang/AnimeAutoMMORPG/.agents/skills/godot-error-dictionary/SKILL.md`; инструкции переписаны под существующую архитектуру Уралии. Сторонний код не добавлен.
