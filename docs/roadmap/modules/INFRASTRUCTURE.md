# Модуль: Инфраструктура

Docker Compose, Caddy, CI, бэкапы, сайт, регламенты выкатки: `docs/DEPLOYMENT.md`, `docs/ships-rpg/RELEASE_PROCESS.md`.

## Требования к поставке (сквозные; реализация в разделе «Поставка и обновления»)

- APK не более 100 МБ (желательно); ресурсы скачиваются в игре; обновление APK через игру (прямой APK, позднее RuStore; Google Play не используется)
- Загрузчик контента и экран загрузки: отдельный этап до первой публичной сборки (P2)
- Автодеплой по решению владельца: серверные обновления выкатываются сразу после проверок (бэкап, миграции, сквозные тесты, очистка тестовых игроков)

## Сайт (R-31)

Лендинг на `https://rikagro.ru/`: описание игры (честно: альфа-тест), скриншоты, актуальная версия и кнопка скачивания (данные из `latest.json`), раздел «Как установить», правила и контакты, пометка об использовании ИИ при создании части графики (требование `docs/AI_CONTENT.md`). Статическая страница без внешних скриптов; админка остаётся на `/admin/`, раздача APK на `/download/`. Сейчас корень домена перенаправляет в админку, лендинг заменит это перенаправление. **Изменение Caddyfile для этого разрешено владельцем (R-39, 2026-11-08).** Статус: ✅ лендинг работает на `https://rikagro.ru/` (`site/`, образ Caddy; версия и кнопка скачивания берутся из подписанного манифеста; скриншоты, установка, раздел об ИИ).
