# codex-task-planner: Уралия

## Порядок работы
1. Прочитай `docs/DECISIONS.md`, `docs/ROADMAP.md`, `docs/PROGRESS.md`, актуальные `docs/tz/` и журнал передачи задач, если он существует.
2. Отдели DONE с доказательствами от IN PROGRESS, BLOCKED, TODO и предложений, требующих решения владельца.
3. Выбери один маленький этап с зависимостями, критериями приёмки, списком файлов и точными тестами; не расширяй задачу самовольно.
4. Не переносить механики из других игр: Уралия сейчас 2D AFK RPG с 5v5, а не 3D MMORPG с джойстиком, авто-путём и общими зонами.
5. После работы обновляй существующие журналы прогресса и handoff, не создавая дублей. Записывай коммит, фактические тесты, блокеры и следующую задачу.
6. Claude и Codex работают последовательно с одним GitHub; перед передачей проверь HEAD и отсутствие незакоммиченных изменений.

## Общие ограничения
Работать только в `maillunex-lang/ufa5` по согласованной задаче. Сверять утверждённые решения с кодом, не переносить 3D MMORPG-механики из AnimeAutoMMORPG. Не трогать Claude MCP, Codex MCP, VPS, другие репозитории, занятые порты, production, секреты и платежи. Никаких внешних зависимостей или исполняемых хуков без аудита и разрешения. Отчёт о файлах, реальных проверках, рисках и следующем шаге.

## Происхождение
Оригинальная адаптация рабочих принципов из собственного репозитория `maillunex-lang/AnimeAutoMMORPG/.agents/skills/codex-task-planner/SKILL.md`; инструкции переписаны под существующую архитектуру Уралии. Сторонний код не добавлен.
