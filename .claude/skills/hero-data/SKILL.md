# Данные героев

Источник истины — JSON-схемы в `schemas/` (`hero.schema.json` и др.). Сначала менять схему и пример в `schemas/examples/`, потом код.
В Godot это custom `Resource`, на сервере те же поля, чтобы формула статов не разошлась.

Статы: сверять с `hero.schema.json` (`base_stats`), новых без схемы не вводить.
Итог = база * рост от уровня * множитель возвышения + предмет. Целочисленно, где важна воспроизводимость.

Навык: id, тип `basic` / `ultimate` / `passive`, цель, коэффициент, статус. У героя 1–4 навыка.
Стадия: вражеская пятёрка, уровни, награда.

id строковый и стабильный. Имя на экране — отдельный ключ локализации (`name_key`), его можно менять.
Любое изменение схемы сопровождать тестом в `tests/test_schemas.py`.

Выход: поля ресурсов и как из определения героя собрать боевое состояние.
