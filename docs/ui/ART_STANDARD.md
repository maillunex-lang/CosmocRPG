# Художественный стандарт космического фона

Статус: утверждён владельцем (2026-11-08). Проверяется автотестами (`art_standard_test`, `background_render_test`).

## Стандарт

- **Глубокий тёмно-синий космос**: база под слоями почти чёрная, холодный синий.
- **Сине-фиолетовые туманности**: основные цвета облаков, фиолетовый и синий.
- **Умеренное бирюзовое свечение**: бирюза есть, но как акцент по краям, а не заливка.
- **Тёмный центр**: корабли, подписи и цели читаются на спокойном фоне; яркие облака по краям, под панелями HUD.

Эталон: три изображения владельца (звёзды, туманность, газ). Измерено: сине-фиолетовых 97% насыщенных пикселей, яркой бирюзы 2,5%, средний оттенок 225°, яркость центра 0,063 (при газе 35%).

## Профиль системы (данные)

Каждая звёздная система имеет профиль фона (JSON в `client/assets/space/backgrounds.json`; позже их редактирует админка). Реестр `textures` связывает ключи с файлами, профиль перечисляет слои.

```json
{ "id": "xi", "name": "Система Кси", "base_color": [0.010, 0.026, 0.066],
  "brightness": 1.0, "intensity": 1.0, "px_per_unit": 14.4,
  "layers": [
    { "texture": "stars_deep", "blend": "add", "parallax": 0.10, "zoom": 1.15, "wrap": "mirror" },
    { "texture": "gas_turquoise", "blend": "mix", "parallax": 0.50, "zoom": 1.30,
      "intensity": 0.35, "tint": [1,1,1], "drift": [3.0, 1.2], "flip": [1,1], "min_quality": "medium" } ] }
```

| Поле слоя | Диапазон | Смысл |
|---|---|---|
| `texture` | ключ реестра | какую текстуру показывать (меняется для каждой системы) |
| `blend` | add / mix | сложение (звёзды, туманность) или наложение с прозрачностью (газ) |
| `parallax` | 0–2 | 0: слой неподвижен, 1: движется как мир; дальние слои меньше |
| `zoom` | 1–3 | запас по размеру, чтобы сдвиг не показывал край |
| `brightness`, `intensity` | 0–2 | яркость и интенсивность слоя (интенсивность: вклад или непрозрачность) |
| `tint` | 0–2 по каналам | оттенок слоя |
| `drift` | ±60 px/с | медленное самодвижение (отключается при «уменьшении анимаций» и на low) |
| `wrap` | clamp / mirror | clamp: край не показывается (мягкое ограничение сдвига); mirror: бесконечная прокрутка |
| `flip` | ±1 по осям | отражение: из тех же текстур получаются разные системы |
| `min_quality` | low / medium / high | с какого пресета графики слой показывается |

Общие поля профиля: `brightness`, `intensity` (0–2) умножают значения всех слоёв, `base_color` (глубокий синий под слоями), `px_per_unit` (масштаб параллакса). Неверные значения не роняют игру: числа ограничиваются, а замечания собираются в `warnings`.

## Пользовательские настройки

Хранятся локально (`user://settings.cfg`, раздел `[ui]`); экран настроек появится в UI-11.

| Настройка | Значения | Действие |
|---|---|---|
| `bg_brightness`, `bg_intensity` | 0–1,25 | множители яркости и интенсивности всех слоёв. Выше 1,25 нельзя: фон выходит из стандарта |
| `graphics_preset` | low / medium / high | low: без слоя газа и без самодвижения |
| `reduce_motion` | да / нет | отключает самодвижение слоёв |

## Как добавить систему или заменить текстуры

1. Подготовить изображения (`tools/optimize_space_assets.py` сжимает и проверяет), положить в `client/assets/space/backgrounds/`, импорт со сжатием VRAM (`compress/mode=2`).
2. Зарегистрировать ключ текстуры и добавить профиль в `backgrounds.json` (или `BackgroundLibrary.register_texture` / `register_profile` из загрузчика контента).
3. Указать профиль в данных системы (`system.background`), экран сам применит его.
4. Запустить `tools/test_client.sh`: стандарт, размеры файлов и целостность каталога проверяются автоматически.

Если текстура отсутствует, подставляется заглушка (сетка в палитре игры), а ключ попадает в `missing_assets()`.

## Производительность и размер

- Три полноэкранных слоя с лёгким шейдером (один выбор текстуры на слой); на пресете low два слоя.
- Текстуры сжаты VRAM (ASTC): звёзды 1672×941, туманность 1536×864, газ 1024×576; в APK около 3,5 МБ, в памяти видеокарты в четыре раза меньше, чем без сжатия.
- Пересчёт параметров шейдера только когда что-то изменилось (камера, самодвижение, размер экрана).
- Исходные большие PNG в репозиторий не входят (хранятся вне его); оптимизированные WebP: 379 КБ вместо 5,76 МБ. Лимиты проверяются тестом: файл не больше 400 КБ, сумма не больше 700 КБ, сторона не больше 2048 px.
