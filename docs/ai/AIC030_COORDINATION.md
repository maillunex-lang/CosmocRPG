# AIC-030 — координация со старым Manager

Цель: новая система AI-цивилизации может резервировать капитанов, чтобы старый `aiagent.Manager` не спавнил их как простые FSM-корабли (избежание видимых двойников).

## Сделано в этой ветке

- `server/internal/aiciv/reservation.go` — in-memory резервация с TTL.
- `aiagent.Manager` получил интерфейс `Reservations` и метод `SetReservations`.
- В `spawnOne` капитаны с `IsReserved == true` пропускаются (не спавнятся старой FSM).
- В `cmd/server/main.go` резервация создаётся и прикрепляется к Manager (флаги по умолчанию выключены, автономный Director ещё не запущен).

## Следующие шаги AIC-030

1. CivilizationDirector, который выбирает цели через Utility/GOAP и вызывает `reservation.Reserve` при взятии капитана.
2. При снятии с управления — `Release`.
3. Учёт глобальных квот (0 людей → grace → снятие видимых).
4. Восстановление intents после рестарта.
5. Метрики количества зарезервированных и нагрузки.

Флаги `COSMOC_AI_CIVILIZATION_*` остаются выключенными. Старая система продолжает работать для незарезервированных капитанов.
