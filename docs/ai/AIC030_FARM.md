# AIC-030 — реальный вход агента + PvE-фарм

## Сделано

- `FarmController` получает `World` и после входа агента вызывает `Snapshot`.
- Выбирает **ближайшего** живого hostile (`Kind=="hostile"`, не Dead).
- Если в снимке ничего нет — fallback на `dr1`/`dr2` с учётом памяти.
- При успехе пишет `observed`, при ошибке — `failure`.
- В `main.go` под флагом gateway запускается один агент с этим поведением.

## Ограничения

- Один агент.
- Нет перецеливания при смерти цели или выходе из дальности.
- Нет Utility/GOAP.
- Флаги выключены по умолчанию.
