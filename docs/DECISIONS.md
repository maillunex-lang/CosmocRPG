| Дата | Решение | Обоснование |

| 2026-11-08 | Стек: Godot 4.7 (клиент), Go (сервер), PostgreSQL, React + TypeScript (админка), Docker Compose, GitHub Actions. | Задан в мастер-промпте №1. |
| 2026-11-08 | Работаем в репозитории `maillunex-lang/CosmocRPG` (приватный), монорепозиторий. | Подтверждено владельцем. |
| 2026-11-08 | VPS = рабочая машина разработки (`78.17.214.25`, Ubuntu 24.04). Другие проекты и их ресурсы не используются. | Подтверждено владельцем. |
| 2026-11-08 | Домена пока нет: доступ к игровому серверу по IP, HTTP/WS без TLS. Админка слушает только localhost, доступ через SSH-туннель. | Нет домена; пароли админки нельзя пускать по открытому каналу. К релизу обязателен домен и TLS. |
| 2026-11-08 | Для Android-тестов нужен ws:// к IP VPS. Проверить при первой Android-сборке; при блокировке разрешить cleartext только для IP VPS. | Android блокирует HTTP для своих сетевых API. |
| 2026-11-08 | Go 1.22 из пакетов Ubuntu. | Достаточно для Этапа 00; обновить при необходимости. |
