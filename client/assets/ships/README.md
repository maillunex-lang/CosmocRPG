# Корабли

Каждый корабль: `assets/ships/<папка>/ship.json` (облики, точки привязки, масштаб, подписи) и файлы GLB. Корабль подключается строкой в `ui/ships/ship_def.gd` (PATHS).

**Временные модели** (`"temporary": true`, пока `tmp_haul`, `tmp_mine`) используют GLB «Стрижа» как заглушку и помечаются в интерфейсе. Чтобы заменить модель, положите новый GLB и поменяйте путь `skins.<облик>.glb` в `ship.json`: игровая логика, сервер и код не меняются.
Нос модели должен смотреть в -X (поле `nose_axis`), длина около 1,9; точки привязки (`points`) подберите под новую модель. Игровые характеристики корабля задаются на сервере (каталог кораблей в админке), а не здесь.
