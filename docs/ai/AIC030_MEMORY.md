# AIC-030 — память в решениях

## Сделано

- `server/internal/aiciv/memory_decide.go`:
  - `ChooseTarget` — читает `Store.Recall`, пропускает subject’ы с недавними `failure`, иначе берёт первый кандидат.
  - `RecordFailure` / `RecordObserved` — пишут в существующий `Store.Observe` (с TTL).
- `FarmController` теперь:
  - выбирает цель из `Targets` с учётом памяти;
  - при успешном старте фарма пишет `observed`;
  - при ошибке `IssueCombat` пишет `failure` (агент будет избегать эту цель ~30 минут).
- В `main.go` передаются кандидаты `dr1`, `dr2`.

## Ограничения

- Память влияет только на выбор цели фарма, не на общий planner/utility.
- Нет опасных маршрутов, предпочтений, социальных отношений.
- События только внутренние, без приватных данных игроков.

## Следующие шаги

1. Писать память и из других действий (добыча, смерть, успешный kill).
2. Использовать память в Utility/GOAP (повышать cost целей с недавними провалами).
3. Опасные маршруты и предпочтения ресурсов.
