# HTTP из Godot

`HTTPRequest`, JSON. На проде HTTPS, локально при разработке допустим http://localhost.
Не ENet и не свой мультиплеер: боя в реальном времени нет.

Токен сессии хранить локально, не в репозитории и не в строке запроса.
UI ждёт ответ и показывает ошибку сети.
Награду на экране брать только из ответа сервера.

Таймаут и один повтор для GET.
POST запуска боя и награды не повторять вслепую. Если ответ потерян, повтор идёт с тем же ключом идемпотентности (`battle_id`).

Базовый URL один, через проектную настройку. Локальный сервер и VPS переключаются настройкой, не правкой кода.

Выход: один клиентский скрипт запросов и какие сигналы он шлёт UI.
