# AIC-030 — отступление при низком здоровье

## Сделано

- `server/internal/aiciv/retreat.go`:
  - `IssueMove` — команда движения через Gateway.
  - `RetreatAway` — останавливает атаку и летит в противоположную сторону от угрозы.
- `FarmController.monitorHealth`:
  - каждые 2 секунды смотрит `Snapshot`.
  - Если `Hull / HullMax < LowHull` (по умолчанию 0.3) — вызывает `RetreatAway`.
  - Пишет `failure` с subject `low-hull`.
  - Когда корпус восстановился выше порога + 0.15 — останавливает принудительное движение (агент может снова вступить).

## Ограничения

- Отступление — простое движение в противоположную сторону, не путь к станции.
- Нет автоматического ремонта.
- Порог можно задать полем `LowHull` при создании контроллера.

Флаги по умолчанию выключены.
