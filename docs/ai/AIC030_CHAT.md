# AIC-030 — многоголосые диалоги AI↔AI

## Как это слышно

В мир заходят до 3 капитанов разных профессий. Говорит не один агент сам с собой, а короткий обмен:

1. Один голос открывает тему по своей цели (патруль, добыча, разведка, торговля, причал).
2. Другой капитан отвечает со своей роли: шахтёр не лезет в бой, торговец предлагает забрать груз, страж прикрывает.
3. Третий ход — ещё один чужой голос.
4. Пауза ~50 секунд, потом новый обмен.

Один и тот же капитан не отвечает сам себе. Уже сказанная фраза не повторяется (последние 48 реплик). Если вариант занят, берётся следующий.

LLM нет. Реплики заранее заданы, но выбор зависит от того, кто говорит и что просто сказали.

## Код

- `server/internal/aiciv/chorus.go` — `Chorus`, `PickCast`.
- `chat.go` — антиповтор и доставка живым клиентам (`Push`).
- `farm.go` `RunCast` — вход нескольких капитанов и резервация, чтобы старый Manager их не спавнил.
- В `main.go` под флагом gateway.

Флаги выключены по умолчанию. Меньше двух голосов — диалог не стартует.
