## 2026-11-08 — Этап 00, шаг 00.3 (Go-сервер)

Сделано: `server/` — `/health`, `/ws` (hello, ping/pong, ошибки, лимит размера и частоты), конфиг из `COSMOC_*`, JSON-логи (slog), корректное завершение по SIGTERM, PostgreSQL (pgx), встроенные миграции с advisory-блокировкой, журнал запусков `server_boots`.

Проверено фактически: `go vet`, `gofmt`, `go test -race` (config, db, httpapi, ws — все прошли, интеграционные тесты БД выполнены на PostgreSQL 16 в Docker); ручной запуск: `/health` 200, WebSocket hello/pong, остановка по SIGTERM с кодом 0, повторный запуск не применяет миграции и сохраняет данные (2 запуска в БД), при недоступной БД `/health` отвечает 503.

Замечания: тесты БД требуют `COSMOC_TEST_DATABASE_URL`, без неё пропускаются, а тесты стирают схему `public`. Использовать только отдельную тестовую базу (сейчас контейнер `cosmoc-pg-dev`, порт 127.0.0.1:55432, пароль временный). В CI база будет поднята как сервис.

Сделано: Go — `internal/admin` (вход по паролю argon2id, сессии с хешем токена в БД, ограничение неудачных попыток по IP и имени, журнал действий, `/api/login|logout|me|status|audit`), отдельный адрес `COSMOC_ADMIN_ADDR` (по умолчанию 127.0.0.1:8081, `off` выключает), миграция 0002, команда `server admin-create` (имя из `COSMOC_ADMIN_USERNAME`, пароль из `COSMOC_ADMIN_PASSWORD` или stdin, минимум 12 символов).
