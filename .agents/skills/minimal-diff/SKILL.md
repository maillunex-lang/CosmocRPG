# minimal-diff: Уралия

## Порядок работы
1. Проверь актуальный `main`, чистоту рабочего дерева и `docs/DECISIONS.md`; работай только над утверждённой задачей.
2. Не переименовывай массово сцены, JSON ID, ресурсы, публичные API или боевые события; стабильность ссылок критична.
3. Для боя отделяй серверную симуляцию от клиентского проигрывания. Не меняй v1 golden при работе над v2.
4. Не заменяй существующие CI, валидаторы и Godot MCP альтернативами без согласования.
5. Проверь diff, тесты и headless импорт Godot, если доступны; не заявляй PASS без запуска.
6. Малые коммиты в `main` без force push согласно `docs/CI.md`; если политика изменилась, следуй актуальному решению владельца.

## Общие ограничения
Работать только в `maillunex-lang/ufa5` по согласованной задаче. Сверять утверждённые решения с кодом, не переносить 3D MMORPG-механики из AnimeAutoMMORPG. Не трогать Claude MCP, Codex MCP, VPS, другие репозитории, занятые порты, production, секреты и платежи. Никаких внешних зависимостей или исполняемых хуков без аудита и разрешения. Отчёт о файлах, реальных проверках, рисках и следующем шаге.

## Происхождение
Оригинальная адаптация рабочих принципов из собственного репозитория `maillunex-lang/AnimeAutoMMORPG/.agents/skills/minimal-diff/SKILL.md`; инструкции переписаны под существующую архитектуру Уралии. Сторонний код не добавлен.
