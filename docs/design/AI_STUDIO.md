# AI Civilization Training Studio

Раздел админки (`https://<хост>/admin/` → кнопка «AI Studio») для создания, обучения, проверки и публикации 300 AI-капитанов.
**В игре запрещены LLM API, облачная генерация текста и зависимость от ChatGPT.** ChatGPT используется только вручную, вне игры:
владелец скачивает ZIP, обучает партию в ChatGPT и загружает результат обратно. В игру попадают готовые данные, которые выбирает движок на правилах.

## Цикл обучения

1. «Обзор» → «Сгенерировать недостающих» (до 300 капитанов, детерминированно, повтор безопасен).
2. «ChatGPT» или «ZIP» → выбрать партию (10, 25, 50 или полный пакет) → скачать ZIP → «Скопировать промпт обучения ChatGPT».
3. В новом чате ChatGPT вставить промпт, приложить ZIP, получить `trained_pack.zip`.
4. Загрузить ZIP в «Импорт»: система проверяет и показывает отчёт и предпросмотр изменений, ничего не меняя.
5. «Подтвердить публикацию»: атомарная публикация новой версии. Откат — на «Обзоре» (создаёт новую версию с прежним содержимым).

## Формат пакета `AI_Civilization_Pack_v1` (schema_version 1)

```
manifest.json            паспорт: schema, schema_version, pack_id, kind (full|partial), created_at, created_by, base_version, batch, captains[], files[{path,sha256}], notes
schemas/*.schema.json    JSON Schema (draft 2020-12) каждого типа файлов; сервер проверяет по своим копиями
captains/cpt-NNNN.json   профили капитанов (id совпадает с именем файла)
dialogue/                intents, synonyms (слова, сленг, опечатки), templates, rules, emotions
knowledge/facts.json     единственный источник игровых фактов
society/                 factions, corporations, relations
behavior/strategies.json
learning/lessons.json
memory/memory_rules.json
scheduler/schedules.json заготовка для будущих систем
tests/dialogue_tests.json
reports/*.md|txt         заметки, не влияют на игру
README_FOR_CHATGPT.md    мастер-промпт (в корне допускаются только документы .md/.txt)
```

Правила слияния (неразрушающее): капитаны заменяются по `id`, ничего не удаляется; профили с `meta.manual = true` защищены (конфликт, перезапись только по явному разрешению); списки разделов объединяются по ключу (`id`).
Полный пакет (`full`) и частичный (`partial`) применяются одинаково: удалять данные пакет не может.

### Безопасность импорта

Лимиты: архив до 16 МБ, до 800 файлов, файл до 2 МБ, всего до 48 МБ после распаковки, степень сжатия до 300. Размеры проверяются по факту распаковки.
Отклоняются: ZIP Slip (`..`, абсолютные пути, `\`, диски, скрытые файлы, глубина больше 3), дубликаты имён, символические ссылки и спецфайлы, зашифрованные записи, типы кроме `.json/.md/.txt`,
исполняемые и вложенные архивы (по сигнатурам), скрипты и команды, не UTF-8, признаки секретов (ключи API, пароли, приватные ключи, токены), запрещённые поля JSON
(`password`, `token`, `api_key`, `private_messages`, `player_progress`, `inventory`, `email` и др.), нарушения JSON Schema, неверные SHA-256, расхождение `manifest.captains` с каталогом `captains/`.
Ссылочная целостность: фракции, корпорации, стратегии, отношения, намерения, факты (`{fact:id}`) и допустимые подстановки (`{player}`, `{captain}`, `{topics}`).
Публикация блокируется, если не пройдены обязательные проверки (структура, факты, контекст, регрессионные диалоги). Атомарность и защита от гонок: одна транзакция, `ExpectActive`, advisory-блокировка.
Загрузка и публикация не затрагивают игровые таблицы (проверено тестом на PostgreSQL).

## Диалоговый движок (`server/internal/aistudio/dialogue.go`)

Нормализация русского текста, исправление опечаток (словарь и расстояние Левенштейна), сленг и синонимы, намерения (примеры и ключевые слова, окончания отсекаются), контекст (правила «расскажи подробнее»), настроение (эмоции), память имени собеседника с ограниченным сроком,
речевые профили (формальность, многословие, юмор, коронные фразы), проверка фактов (шаблон с неизвестным фактом отбрасывается), защита от повторов, безопасные уточняющие ответы вместо выдумок.
Интерфейс `SemanticSearcher` оставлен для будущего локального семантического поиска. LLM не подключены, сетевых вызовов нет.

## Академия

Симулятор диалога, групповые разговоры, экзамены: структура и ссылки, уникальность, намерения, характер, факты, контекст, память, повторы, безопасные уточнения, регрессионные диалоги из `tests/dialogue_tests.json`. Результаты сохраняются и видны в админке.

## Игровые ники

Имена капитанов — игровые ники в духе онлайн-игр, русские и английские вперемешку (сейчас 120 с кириллицей и 180 латиницей из 300). Список (`nicknames_data.go`, около 580 ников) составлен вручную по типичным шаблонам игровых ников:
животные, стихии, ремёсла, космос, ирония, стилизованные с цифрами и подчёркиваниями; без названий брендов, персонажей франшиз и ников реальных игроков. Назначение детерминированно по номеру капитана.
Кнопка «Применить игровые ники» (Обзор) переименовывает всех, кроме профилей, правленных вручную; в биографии вместо имени ставится «Он/Она»; операция идемпотентна и откатывается как обычная версия.

## Ограничения

- Качество ответов ограничено правилами и данными: движок честно уточняет, а не выдумывает.
- Генератор даёт стартовые профили; художественную глубину добавляет обучение через ChatGPT.
- Нагрузочные испытания не проводились. Интеграция с игровым миром (капитаны как объекты мира) не сделана.
