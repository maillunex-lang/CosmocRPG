# context-budget: Уралия

## Порядок работы
1. Перед задачей определи точный модуль и критерии приёмки; сначала прочитай релевантные разделы `docs/DECISIONS.md`, `docs/ARCHITECTURE.md`, `docs/PROGRESS.md`.
2. Ищи файлы по именам и символам в `client/`, `server/`, `data/`, `schemas/`, `tools/`, `tests/`, `docs/`. Не читай весь репозиторий без причины.
3. Подключай один основной и максимум один вспомогательный навык; при риске безопасности или неполной картине расширяй контекст.
4. Не сокращай проверки, согласования, тесты и аудит секретов ради экономии токенов.
5. В конце дай краткий результат: изменённые пути, проверенные команды, проблемы, следующий шаг. Не заявляй измеренную экономию токенов без телеметрии.

## Общие ограничения
Работать только в `maillunex-lang/ufa5` по согласованной задаче. Сверять утверждённые решения с кодом, не переносить 3D MMORPG-механики из AnimeAutoMMORPG. Не трогать Claude MCP, Codex MCP, VPS, другие репозитории, занятые порты, production, секреты и платежи. Никаких внешних зависимостей или исполняемых хуков без аудита и разрешения. Отчёт о файлах, реальных проверках, рисках и следующем шаге.

## Происхождение
Оригинальная адаптация рабочих принципов из собственного репозитория `maillunex-lang/AnimeAutoMMORPG/.agents/skills/context-budget/SKILL.md`; инструкции переписаны под существующую архитектуру Уралии. Сторонний код не добавлен.
