# Безопасность

## Правила

- Секреты не попадают в GitHub. `.env`, `secrets/`, ключи и keystore в `.gitignore`. Образец переменных: `.env.example` без значений.
- Пароли хранятся только в виде хеша (argon2id).
- Ограничение частоты запросов, проверка прав, валидация входных данных.
- WebSocket-сессии защищены от повторного использования и подмены токена.
- Операции с валютой и предметами только в транзакциях БД.
- Завершение фоновых заданий идемпотентно.
- Критические административные действия пишутся в журнал.
- PostgreSQL не публикуется наружу, доступен только внутри сети Docker.
- Резервное копирование настраивается и проверяется восстановлением.
- Админка не запускает пользовательский код.
- Клиентским расчётам экономики и боя не доверяем.

## Текущие ограничения (Этап 00)

- Нет домена: игровой порт (8080) работает по HTTP/WS без шифрования, до появления домена не использовать реальные пароли игроков.
- Админка по HTTPS с самоподписанным сертификатом (Caddy), вход по паролю; по умолчанию порт привязан к `127.0.0.1` (доступ через SSH-туннель), открытие наружу решает владелец (`ADMIN_BIND`).
- PostgreSQL и админ-API (:8081) наружу не публикуются. Docker обходит `ufw`, поэтому защита держится на привязке портов, а не на файрволе.

## Поставка контента и обновлений

- Манифест контента подписан; клиент проверяет подпись и SHA-256 каждого набора до подключения.
- Скачанные наборы содержат только данные, без исполняемого кода.
- Самообновление APK (канал: прямая раздача, позднее RuStore): только по HTTPS, с проверкой хеша и подписи; APK подписан постоянным ключом, который хранится вне репозитория. Потеря ключа означает невозможность обновлять установленные копии.

## Release-подпись Android

- Постоянный ключ создан 2026-11-08: `~/keys/cosmoc/release.keystore` (PKCS12, RSA 4096, алиас `cosmoc-release`, действует до 2054-03-26). Пароль и пути в `~/keys/cosmoc/release.env` (права 600, каталог 700). Всё вне репозитория.
- Отпечаток сертификата SHA-256 (публичный, для сверки): `D1:26:00:89:E6:B7:E6:3B:68:A2:C8:98:3D:F5:74:99:6D:4C:0B:AB:DF:5D:48:D0:68:48:39:0C:D8:1E:24:9F`.
- **Потеря ключа или пароля = невозможность обновлять установленные копии игры** (в том числе обновление через игру). Нужна резервная копия `release.keystore` и `release.env` вне VPS (менеджер паролей / офлайн-носитель). Статус копии: **не сделана, ответственный: владелец**.
- Сборка release-APK: `. ~/keys/cosmoc/release.env && godot --headless --path client --export-release "Android" <файл.apk>` (Godot берёт ключ из переменных `GODOT_ANDROID_KEYSTORE_RELEASE_*`; в CI они будут храниться как GitHub Secrets).
- Не использовать release-ключ для debug-сборок; debug-ключ (`~/.android/debug.keystore`) публичный по паролю и для релиза не годится.
- Данные в сертификате (CN/O/C: `Zvezdnye Rubezhi` / `CosmocRPG` / `RU`) заданы временно и в готовом ключе не меняются; если нужны другие, ключ надо создавать до первой публикации.
