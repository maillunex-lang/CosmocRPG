## Исторический foundation-checkpoint 2026-11-09 (новый статус ниже)

Добавлен только фундамент AIC-010: bounded GOAP + utility, запрет неутверждённых/запрещённых действий, identity/retention memory store, additive SQL0022 и опциональный shadow sync Studio. Флаг COSMOC_AI_CIVILIZATION_SHADOW=false по умолчанию; требует COSMOC_FEATURE_AI=true. Shadow сохраняет до 16 идентичностей за шаг, не создаёт player, не спавнит/деспавнит, не начисляет средства и не меняет чат. Политика Capabilities не является защитой ещё не подключённых gameplay endpoints; её обязательно применить в AIC-020. Bind внутренний, не API авторизации. Память этого этапа — только внутренние подтверждённые метаданные событий, не законченная epistemic-модель AI-005.

Старая FSM и чат остаются действующими. **Не считать AI.md реализованным.** Нет новых активных AI-персонажей, рабочего gateway, социального графа, библиотеки1–2тыс. конструкций, оценки4/5 или canary. Не включать shadow в production без релизной проверки миграции. Сохранённые Studio-ID не удаляются при смене пакета. Сценарии сохранности/TTL/CAS/конкуренции проверяются отдельно на PG.

## Порядок и параллельность

Критический путь: AIC-010→020→030→100. Speech contract AIC-040 может разрабатываться независимо от gateway; endpoints world/WS и actor visibility трогать согласованно с работой оборудования. Не присваивать агентам задачи без распоряжения владельца. Внешние LLM всегда выключены. AI-only предприятия запрещены, социальное доверие не создаёт ACL. Сначала две равные человеческая/AI операции через один путь, затем bootstrap 300 профилей, затем canary; нельзя сразу заменить видимые корабли300 игровыми персонажами.

## Приёмка

Серверные race+отдельная PG; отсутствие двойных наград после restart/multi-worker; human regressions; реальный Godot WS; TypeScript/tests админки; replay100–300 диалогов и независимая оценка качества; нагрузка и замеры VPS. Для отсутствующих механик проверять отказ без списаний/обещаний успеха. DONE по коду не означает включение на сервере/APK. Production пока не изменялся.
