```bash

cd server && gofmt -l . ; go vet ./...
PW=$(sudo -n docker inspect cosmoc-pg-dev --format '{{range .Config.Env}}{{println .}}{{end}}' | grep '^POSTGRES_PASSWORD=' | cut -d= -f2-)
USERN=$(sudo -n docker inspect cosmoc-pg-dev --format '{{range .Config.Env}}{{println .}}{{end}}' | grep '^POSTGRES_USER=' | cut -d= -f2-)
COSMOC_TEST_DATABASE_URL="postgres://$USERN:$PW@127.0.0.1:55432/cosmoc_test?sslmode=disable" go test ./...   # пароль не выводить

# Клиент: отдельный тест
cd client && godot --headless --path . --script res://tests/hud_test.gd     # ищите строки FAIL и «Итого»
# Полный набор: список в tools/test_client.sh (сетевые тесты требуют COSMOC_TEST_WS_URL)
# На чистой копии репозитория сначала: godot --headless --path client --import

# Админка

```

Сквозная проверка на production (после выкатки): короткий скрипт Godot (`--script`) с `ServerGateway` и `PlayerIdentity.set_override("<16+ символов>")`
подключается к `wss://rikagro.ru/ws`, создаёт персонажа с ником-меткой (например `Zz_…`) и проверяет нужное; затем тестового игрока удаляют
SQL по **точному** имени и времени создания:


## 5. Повторяющиеся ошибки и как их решать

Читайте перед работой; каждый пункт стоил времени хотя бы один раз.

### Процесс
- **Не смотреть CI после push.** Клиентская задача CI («Клиент (Godot)») тихо падала несколько версий подряд. После каждого push: `gh run list --limit 3`;
  упало — `gh run view <id> --log-failed`. Чинить сразу.
- **Ожидание.** Команды вида `sleep N; …` инструмент может блокировать. Ждите через `gh run watch <id>` (в фоне) или периодические проверки статуса.
- **Удаление файлов.** Прямой `rm` могут блокировать проверки безопасности: используйте `git rm`, `find <каталог> -name '<маска>' -delete`; не обходите блокировку.
- **Секреты и ключи.** `*.pem`, `.env`, `~/keys` не коммитить и не печатать. Файла ключа нет в CI: тесты не должны от него зависеть (см. `updater_test`).
- **Временные файлы** — в каталог scratchpad сессии, не в репозиторий и не в `~/apk-share` (он раздаётся публично).
- **Тестовые игроки на production** удалять сразу, по точному имени; не оставлять данные в базе.
- **Локальный тестовый сервер**: старые процессы могут держать порты 18082/18083 — запускайте на свободном (например 18095) и проверяйте `ss -ltnp`.

### Go (сервер)
- **Новый тип сообщения WebSocket** обязательно добавить в список известных типов в `server/internal/ws/hub.go` (строка со `case "join", "create_character", …`),
  иначе клиент получит `unknown_type`, хотя обработчик написан.
- **Тесты с БД**: `testdb.Pool(t)` вызывать с `t` подтеста (`t.Run`), а не родительского — иначе пропуск без БД превращается в панику.
- **`gofmt -l .`** перед коммитом (CI проверяет форматирование); `go vet ./...`.
- **Сигнатуры мира**: `world.Join(Record{...})`, `SetTarget` возвращает `bool`, `SetAttack` — `error`. Не угадывать — читать `server/internal/world/*.go`.
- **Миграции** только расширяющие, нумерация следующая по порядку (следующая свободная — `0018`), применённые не менять. Проверять тестом `db`.
- Не называть переменные именами встроенных типов (`any`), не делать общих хранилищ без экспорта: для тестов соседних пакетов нужен экспортируемый `NewMemStore()`.
- В тестах HTTP-клиент Go «чистит» `..` в адресе: путь с обходом проверять как `%2e%2e%2f`.
- Журнал в `slog` — по-русски, без секретов и персональных данных.

### Godot (клиент)
- `var x := …` не работает, если тип нельзя вывести (значение из `Dictionary.get()`/нетипизированного `Array`) — писать тип явно: `var x: Array = …`.
- `Dictionary.merged(other)` по умолчанию **не перезаписывает** существующие ключи — передавать `true`.
- В тестах `--script` автозагрузки как идентификаторы недоступны: `const Session := preload("res://ui/session.gd")`, нужные классы — через `preload`.
- `ProgressBar.step` по умолчанию 0,01 — доли округляются; для долей ставить `step = 0.001`.
- Переменная `_input` конфликтует с `Node._input` — называть иначе (`_edit`).
- После `reparent` у узла с уникальным именем `%Имя` восстановить `owner = self`.
- Тема назначается экрану позже `_ready`: стили карточек собирать из токенов (`ui/theme/tokens.gd`), а не брать из темы.
- Пустой `MultiMesh` рисует объект в (0,0) — не создавать без экземпляров.
- `PanelContainer` по умолчанию `mouse_filter = STOP` и **блокирует прокрутку** внутри `ScrollContainer`; автозагрузка `TouchScroll` переводит такие рамки в `PASS`
  (кнопки не трогает: случайных нажатий при прокрутке нет). Новое содержимое ставить внутри `ScrollContainer`, если оно может не поместиться на экране 1280×720.
- Содержимое экранов должно помещаться в 720 px по высоте или прокручиваться (профиль, настройки, магазин) — проверять тестом размера.
- **Запуск `godot --headless --quit` падал (SIGABRT) на чистом профиле**, если сразу стартовали две сетевые проверки. Фоновые сетевые задачи запускать с задержкой
  (3 с после старта). Воспроизведение: `XDG_DATA_HOME=$(mktemp -d) godot --headless --path client --quit`.
- Новые `.gd` создают файлы `.uid` — они должны попадать в коммит (`git add -A client`).
- Пароль/ключ/пути пользователя в клиентских тестах не использовать; сетевые тесты берут адрес из `COSMOC_TEST_WS_URL`.
- Рендер-тесты требуют `xvfb-run`; в CI предупреждения Vulkan при них нормальны.

### Android и сборка
- Каталог `client/android/build` — gradle-шаблон. В git **не** хранятся `libs/` и сгенерированные `src/main/assets/` (см. `.gitignore`);
  обязателен файл `.gdignore` (иначе редактор Godot импортирует шаблон и ломает сборку). Если после правок в git появились файлы из `assets/` — удалить из индекса.
- В `export_presets.cfg` должно быть `gradle_build/compress_native_libraries=true`, иначе APK весит ~87 МБ вместо ~39 МБ.
- Свой код Android: `ApkInstallerPlugin.java`, `UpdateFileProvider.java` (у Godot уже есть FileProvider с тем же классом — конфликт манифеста лечится подклассом).
- Версия: `config/version` и `version_code` в `project.godot` + `version/name` и `version/code` в `export_presets.cfg` — всегда вместе.
- Описание релиза пишите правдиво (однажды в нём назвали ИИ «живыми пилотами» — пришлось перепубликовать).

### Админка (React)
- CSP Caddy: `default-src 'self'`; изображения `'self' data:`, соединения `'self'`. Любой внешний скрипт, шрифт, CDN и `blob:` заблокированы — библиотеки только из сборки.
- Секреты и ключи в интерфейсе не показывать; действия администратора пишутся в журнал (`audit_`).
