# Карта экранов

Только Landscape, **в обе стороны с автоповоротом по датчику** (`sensor_landscape`, решение владельца после проверки на iQOO 15R: телефон удобно держать любой стороной, вырез камеры бывает слева или справа). Портретной ориентации нет. База 1280×720 (16:9); `stretch=canvas_items`, `aspect=expand`: на более широких экранах добавляется ширина, высота остаётся 720.

## Слои клиента (сверху вниз)

1. **Alerts** — боевые тревоги и уведомления (всегда сверху, не блокируют ввод PvP).
2. **Modals** — подтверждения, загрузка.
3. **Screens** — экраны центра (стек `ScreenRouter`), один активный.
4. **HUD** — постоянный интерфейс космоса.
5. **World** — 2.5D-космос: 2D-фон + 3D-корабли в SubViewport.

## Навигация

- Стек: `push(экран)`, `pop()` (Назад), `close_all()` (Закрыть → Космос), `replace()`.
- Запоминается последняя вкладка Командного центра и фильтры каждого экрана (в `user://ui_state.cfg`, это только удобство, не данные игры).
- Боевая тревога поверх любого экрана, не закрывает его и не ставит игру на паузу.
- Открытие любого экрана не останавливает космос и PvP.

## Состояния каждого экрана

Загрузка · данные · пусто · ошибка (с повтором) · нет соединения · «Скоро» (функция не реализована) · «Демо» (данные mock).

## Экран «Космос» (UI-02, реализован)

Сцена `scenes/space.tscn`: слой мира (звёздный фон с параллаксом, 3D-корабли-заглушки в SubViewport, ортографическая камера с лёгким наклоном и плавным следованием) и поверх него `scenes/hud.tscn`. HUD собран из трёх колонок-контейнеров, поэтому блоки не накладываются:

| Колонка | Содержимое |
|---|---|
| Левая | профиль и состояние корабля (корпус, щиты, энергия), «Задания» (сворачиваемая), «Чат» (сворачиваемая, по умолчанию свёрнута), внизу виртуальный джойстик |
| Центральная | плашка «Демо» с кнопкой «Выйти», тревоги и уведомления, внизу «Карта», «Флот», «Меню» |
| Правая | сверху кредиты и «Настройки»; внизу карточка цели, «Атаковать», 4 способности (сетка 2×2), «Автопилот» и «Авто-навыки» |

В бою «Задания» и «Чат» сворачиваются, тревоги остаются; после боя возвращается выбор игрока. Открытие окна подтверждения не останавливает игру. Выход: кнопка «Выйти», Escape, системная кнопка «Назад».

Вход: с экрана подключения кнопка «Космос (демо)»; «Войти в космос» (серверный мир) пока в состоянии «Скоро».
