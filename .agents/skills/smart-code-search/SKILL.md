# smart-code-search: Уралия

## Порядок работы
1. Сначала проверь `docs/ARCHITECTURE.md`, `docs/DECISIONS.md` и путь нужной подсистемы.
2. Для боя ищи в `server/uralia_server/battle/` и `client/scripts/`; для контента в `data/`, `client/data/`, `schemas/`, `tools/validate_world.py`; для релиза в `.github/workflows/` и `tools/`.
3. Исключай бинарные атласы, импорт Godot, кеши, `.git`, `.venv`, `_local` из текстового поиска.
4. Перед правкой найди определения, вызывающие места, ссылки на ресурсы и тесты; различай источник данных и производную копию.
5. Если файл или функция не найдены, сообщи об этом, не выдумывай путь. Не показывай секреты и приватные настройки.

## Общие ограничения
Работать только в `maillunex-lang/ufa5` по согласованной задаче. Сверять утверждённые решения с кодом, не переносить 3D MMORPG-механики из AnimeAutoMMORPG. Не трогать Claude MCP, Codex MCP, VPS, другие репозитории, занятые порты, production, секреты и платежи. Никаких внешних зависимостей или исполняемых хуков без аудита и разрешения. Отчёт о файлах, реальных проверках, рисках и следующем шаге.

## Происхождение
Оригинальная адаптация рабочих принципов из собственного репозитория `maillunex-lang/AnimeAutoMMORPG/.agents/skills/smart-code-search/SKILL.md`; инструкции переписаны под существующую архитектуру Уралии. Сторонний код не добавлен.
