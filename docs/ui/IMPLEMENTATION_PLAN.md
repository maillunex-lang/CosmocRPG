## 3. Ключевые риски и зависимости

1. **Серверная часть игры не существует.** Без `DemoGateway` интерфейс нечем наполнить. Каждый этап UI делается на mock с плашкой «Демо»; реальные данные подключаются по мере появления серверных модулей (Этап 01 и далее по ROADMAP).
2. **Нет аккаунтов игроков** — вход, права, чат, корпорации невозможны вживую.
3. **Нет устройства/эмулятора** — SDK и сборка APK есть, но проверка на телефоне и производительность отложены до UI-12.
4. **Незавершён Этап 00** (00.6–00.8: Docker Compose, Caddy, CI, сквозная проверка).
5. Производительность 3D на телефоне проверить можно только на устройстве; на VPS рендеринг программный (llvmpipe), скриншоты не показывают реальную скорость.
