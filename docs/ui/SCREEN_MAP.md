# Карта экранов

Только Landscape. База 1280×720 (16:9); `stretch=canvas_items`, `aspect=expand`: на более широких экранах добавляется ширина, высота остаётся 720.

## Слои клиента (сверху вниз)

1. **Alerts** — боевые тревоги и уведомления (всегда сверху, не блокируют ввод PvP).
2. **Modals** — подтверждения, загрузка.
3. **Screens** — экраны центра (стек `ScreenRouter`), один активный.
4. **HUD** — постоянный интерфейс космоса.
5. **World** — 2.5D-космос: 2D-фон + 3D-корабли в SubViewport.

## Навигация

- Стек: `push(экран)`, `pop()` (Назад), `close_all()` (Закрыть → Космос), `replace()`.
- Запоминается последняя вкладка Командного центра и фильтры каждого экрана (в `user://ui_state.cfg`, это только удобство, не данные игры).
- Боевая тревога поверх любого экрана, не закрывает его и не ставит игру на паузу.
- Открытие любого экрана не останавливает космос и PvP.
