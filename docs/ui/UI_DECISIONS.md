# Решения по интерфейсу

## Утверждённые владельцем (не менять без согласования)

| № | Решение |
|---|---|
| UI-01 | Главный экран — живой космос: 3D-корабли, игроки, AI-капитаны; интерфейс компактный, космос занимает основную площадь. |
| UI-02 | Гибридный HUD (Landscape): сверху слева профиль/уровень/состояние корабля; сверху справа валюты, уведомления, настройки; слева задания и сворачиваемый чат; справа цель, атака, способности, автопилот; снизу слева опциональный джойстик; снизу по центру «Карта», «Флот», «Меню». В бою второстепенные панели сворачиваются, предупреждения об опасности остаются. |
| UI-03 | Командный центр, 6 категорий: Капитан, Промышленность, Экономика, Сообщество, Активности, Сервис. Быстрые переходы, запоминание последней вкладки. |
| UI-04 | Звёздная карта: гибридная 2.5D, масштаб, перемещение, карточки, слои (маршруты, фракции, опасности, ресурсы, торговля). Маршруты считает сервер. |
| UI-05 | Бой: автоатака, 3–4 способности, ручное/автоматическое применение, выбор и переключение цели, опциональный джойстик. Сервер проверяет дальность, энергию, перезарядку, результат. Подтверждение атаки нейтрального игрока. PvP идёт при открытых меню. |
| UI-06 | Гибридный 3D-ангар: центральная модель, карточки флота, вкладки «Модули», «Улучшения», «Эскадра». Флагман + до 4 кораблей сопровождения. Для MVP одна переиспользуемая сцена. |
| UI-07 | Станция: выбор, подход, проверка доступа, стыковка, услуги (ремонт, рынок, верфь, контракты, склад, производство, корпорация, информация), отстыковка. Защиту в доке и доступ — только после согласования серверных правил. |
| UI-08 | Экономический центр: «Рынок», «Торговля», «Производство», «Исследования». Покупки подтверждает сервер; при смене цены — новое подтверждение. |
| UI-09 | Социально-корпоративный центр: «Обзор», «Состав», «Дипломатия», «Территории», «Операции». Чат поверх космоса, разворачивается на весь экран; каналы: общий, система, корпорация, личные. Права по серверным ролям; отметка AI в профиле. |
| UI-10 | Центр экспедиций: «Экспедиции», «Задания», «Награды», «Прогресс». Лимит накопления офлайн-результатов 12 ч (конфигурируемо). Расписания и логистические цепочки — заготовка расширяемости, без реализации. |
| UI-11 | Premium Hybrid Sci-Fi. Палитра: фон `#081421`, поверхности `#14283C`, акцент `#42C6E5`, второй акцент `#9575E8`, редкие награды `#F3C46B`, опасность `#F16C79`. Полупрозрачные панели, анимации открытия 150–250 мс, пресеты графики (низкий/средний/высокий), уменьшение анимаций, масштаб текста. |
| UI-12 | Контекстная навигация: единая история, «Назад»/«Закрыть», запоминание вкладок и фильтров, быстрые переходы, приоритет боевых предупреждений, меню не останавливает PvP, подтверждение опасных действий, защита длительных операций от повторов. |

## Технические решения (приняты в UI-00, 2026-11-08)

| Решение | Обоснование |
|---|---|
| Собственный `ScreenRouter` (стек, вкладки, приоритеты) вместо аддона UIFlow/AppNavigation. | Параллельного менеджера в проекте нет; требования (боевой приоритет, запоминание вкладок, блокировка повторов) специфичны, ядро около 150 строк и покрывается тестами. AppNavigation под AGPL; UIFlow рассчитан на Godot 4.6 и тянет лишнее. |
| Собственный виртуальный джойстик. | Около 80 строк; готовые аддоны не учитывают нашу схему зон ввода и PvP-приоритет. Virtual Joystick DX (MIT) остаётся запасным вариантом. |
| Скины панелей и кнопок: Kenney UI Pack Sci-Fi (CC0) как основа, перекрашенная в палитру UI-11; дальше свои 9-patch. | Ускоряет старт, лицензия CC0. Проверить наличие и лицензию файлов при загрузке. |
| **Шрифт: Golos Text** (решение владельца, 2026-11-08), вариативный, OFL 1.1, `client/ui/fonts/`. Один файл для всех начертаний (вес через `FontVariation`), 184 КБ, укладывается в бюджет APK. | Современный, читается на малых экранах Android, кириллица, не «офисный». Лицензия и метаданные проверены по репозиторию google/fonts. |
| Единая `Theme` (`res://ui/theme/`), цвета и размеры как токены; вёрстка контейнерами, без фиксированных координат. | Требование промпта; масштаб текста и пресеты через токены. |
| Данные экранов берутся через слой `UiGateway` (интерфейс) с двумя реализациями: `ServerGateway` (WebSocket) и `DemoGateway` (mock, явная плашка «Демо»). | Серверных API игры пока нет (см. IMPLEMENTATION_PLAN); рабочий режим не подменяется выдуманными данными. |
| Безопасная зона (`DisplayServer.get_display_safe_area`) учитывается корневым контейнером HUD и **пересчитывается при каждом повороте** (вырез камеры оказывается то слева, то справа). | Вырезы экранов Android; ориентация `sensor_landscape` (`window/handheld/orientation=4`). |

## Принято в UI-01 (2026-11-08)

| Решение | Обоснование |
|---|---|
| Тема собирается кодом из токенов (`UiTheme.build(text_scale)`), корневой экран присваивает `theme = UiTheme.build()`. | Один источник цветов и размеров; масштаб текста (UI-11) меняется параметром; нет рассинхрона с `.tres`. |
| Производные цвета вне утверждённой палитры: `SURFACE_RAISED #1D3854`, `SURFACE_SUNKEN #0C1B2C`, `TEXT #E8F2FA`, `TEXT_MUTED #93A9BF`, `SUCCESS #5FD6A0`. **Ждут подтверждения владельца.** | Нужны для состояний кнопок, полей ввода, читаемого текста и статуса «успех»; контраст проверен тестом (текст не ниже 4,5:1). |
| Логические размеры интерфейса: высота не меньше 720, ширина растёт (`stretch=canvas_items`, `aspect=expand`); раскладка проверяется на логических размерах. | Так работает stretch; физические разрешения пересчитываются в логические. |
| Нажимаемые элементы не ниже 56 логических px. | Удобство касания на телефоне (не меньше 48 dp). |
| Кнопка действия имеет состояние «Скоро» и защиту от повторного нажатия на уровне компонента. | Требования промпта: никаких декоративных кнопок, защита длительных операций от повторов. |
