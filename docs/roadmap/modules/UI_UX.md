## MAP-UX-20261110 — отдельная ветка codex/parallel-options

Реализованы поиск и избранное систем, фильтры объектов, локальные избранные точки с центрированием, подписи исследуемых объектов и расширенная легенда; панель карты прокручивается. Клиентские тесты 306 PASS (Godot 4.6.3 headless), подробности в HANDOFF. Это код в отдельной ветке, без интеграции в main, APK и production; визуальная приёмка Android ещё требуется.
