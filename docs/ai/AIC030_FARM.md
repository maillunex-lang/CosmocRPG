# AIC-030 — реальный вход агента + PvE-фарм

## Сделано (минимально)

- `server/internal/aiciv/farm.go` — `FarmController`:
  - `EnsurePlayer` через Bootstrapper (постоянный player из Studio captain).
  - `OpenGateway` на loopback WS.
  - `IssueCombat` на учебный дрон `dr1`.
- В `main.go` под флагом `COSMOC_AI_CIVILIZATION_GATEWAY`:
  - Director резервирует до 8 капитанов из Studio.
  - Через 3 секунды после старта пытается завести в мир **одного** агента и начать фарм `dr1`.
- Враги уже агрятся на любого игрока в `w.players` (включая AI).

## Ограничения

- Только один агент, только известная цель `dr1`.
- Нет выбора ближайшего врага, нет planner/utility, нет снимка мира.
- Gateway живёт пока жив сервер; при остановке закрывается.
- Флаги выключены по умолчанию. Включать только на тестовом сервере.

## Следующие шаги

1. Брать цель из снимка мира (ближайший hostile), а не жёсткий `dr1`.
2. Несколько агентов с квотой.
3. При смерти/выходе из дальности — перецеливание или возврат на станцию.
4. Подключить Utility/GOAP для выбора цели.
