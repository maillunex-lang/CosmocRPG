# AIC-030 — PvE-фарм для AI-игроков

## Текущее поведение мира

В `world/living.go` → `stepEnemy` враги (пираты и др.) агрятся на **любого** игрока из `w.players`:
- не мёртв,
- не в сейф-зоне,
- в радиусе `Aggro` и в пределах `Leash`.

Флаг `p.ai` нигде не исключается. Как только AI-игрок зайдёт через Gateway и появится в `w.players`, пираты будут считать его обычным игроком.

Старые FSM-корабли (`aiShip` в `ai_ships.go`) в `w.players` не входят и в бой не участвуют.

## Что добавлено

`server/internal/aiciv/combat.go`:
- `IssueCombat` — отправляет `target` + `attack` через существующий Gateway.
- `StopAttack` — выключает автоатаку.

Все правила (дальность, энергия, смерть, награды) остаются в обычной симуляции мира. AI не получает особых прав.

## Следующие шаги

1. Director получает снимок ближайших hostile NPC (через обычный снапшот мира).
2. Выбирает цель через Utility/GOAP и вызывает `IssueCombat`.
3. Резервирует капитана, чтобы старый Manager не спавнил его как FSM.
4. При смерти / выходе из боя — `StopAttack` + Release.

Флаги новой системы по умолчанию выключены. Поведение включается только для зарезервированных и подключённых через Gateway AI-игроков.
