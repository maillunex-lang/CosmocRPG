# K-1B — клиент корпораций

Ветка `feature/corporation-client`, база `c297607`, реализация `b9b29e9`. Владелец выбрал этот этап 2026-11-10. Реализация проверена локально; main, production и APK не опубликованы.

## Поведение

- Меню → «Корпорация». Меню и длинный состав прокручиваются.
- Без членства: бесплатное открытое вступление по точному названию/тегу или создание за 10 000 кредитов с подтверждением.
- При членстве: тег, название, казна, имена участников и серверные роли. Управление ролями и переводы в казну не добавлены.
- Выход требует подтверждения. Правила выхода основателя остаются серверными; клиент предупреждает об отсутствии передачи прав.
- Тег и название видны в профиле и обновляются по ответам сервера.
- Неизвестное состояние (вход/потеря связи/timeout) не показывает формы как будто членства нет. После timeout доступно обновление, повтор изменения автоматически не отправляется.
- ID ответов изолируют ошибки корпораций от магазина/боя. Повторные запросы блокируются до ответа/timeout; запоздавшие ответы после timeout игнорируются.
- Android «Назад»: сначала отмена подтверждения, затем закрытие экрана, без выхода из игры. В демо экран недоступен.

Серверный протокол и БД не менялись. После создания/вступления клиент перечитывает `corp_info`, поскольку ответ вступления не содержит состав. Списание и все права определяет существующий сервер.

Сценарий Go запускает отдельный сервер с хранилищами в памяти; production и внешние БД не используются. Проверка нового подключения доказывает восстановление клиентом серверного членства, но не проверяет рестарт PostgreSQL: серверное хранение в этом этапе не менялось.

Повторение (нужен настоящий Go в PATH):

```sh
godot --headless --path client --script res://tests/corporation_test.gd
cd server
COSMOC_TEST_GODOT=godot go test -race -count=1 ./internal/ws -run '^(TestCorporationGodotClient|TestPassportGodotClient)$'
go vet ./internal/ws
```

Оба новых сценария включены в `tools/test_client.sh`. Полный скрипт/CI здесь не запускался. Проверка на целевом Godot 4.7.2, реальная отрисовка, экранная клавиатура и приёмка на Android-устройстве остаются следующими проверками; APK не собран. Изменение не исправляет существующую серверную транзакционность создания корпорации и не добавляет AI-полномочий.
